# Skills

Agent skills shared by Claude Code, Codex and Gemini CLI. Claude Code reads them through the `.claude/skills` symlink.

Most skills started as copies of upstream repos. The copies here are forks: many have local edits, and nothing tracks upstream. To take an upstream change, diff it against the copy here and merge by hand.
